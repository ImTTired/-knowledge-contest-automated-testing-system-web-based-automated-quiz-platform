# 广东省学生军事理论知识竞赛，知识竞赛，自动考试器，自动网页答题，knowledge contest, automated testing system, web-based automated quiz platform
## 本地答题辅助工具 QuizAssistant，自动完成网页考试答题，只需点击提交，无需一道道题点击


**V3 版本最适配广东省学生军事理论知识竞赛，参加该竞赛建议优先使用 V3。V1、V2 为历史开发版本，不推荐使用。V4 面向更多其他考试，新增文档、表格导入题库和离线查答案功能。**

**每个版本文件夹中均包含本版本的使用说明，请先阅读对应版本的说明再运行。** V4 另附 Word、Markdown（已删除） 格式的完整教程和更新记录。

> V4 可以通过自建题库辅助更多考试，但导入题库不等于自动适配考试网站。目前网页自动填写仅支持已适配的高校练习和高校模考页面；其他平台可以先使用离线查询，网页自动填写需要另行适配。（小概率会存在其他网页未经测试导致不匹配问题，请留言）

## 版本选择

| 版本 | 适用场景 | 建议 |
|---|---|---|
| V1 | 高校练习辅助 | 历史开发版本，不推荐使用 |
| V2 | 增加高校模考功能，但无法解决超越题库的问题 | 历史开发版本，不推荐使用 |
| V3 | 完全适配广东省学生军事理论知识竞赛，无法判断的题目交由人工完成| 该竞赛优先选择 |
| V4 | 支持导入其他考试资料构建题库，离线查询或使用现有网页适配 | 需要自建题库时选择 |

工具内置 **4732 道有效题目**，支持单选、多选和判断题，按题干、题型及选项内容匹配，兼容题目顺序和选项顺序变化。源资料另有 1 道重复选项题被隔离，未计入有效题库。

登录、身份信息填写及最终提交由使用者本人操作。所有信息均在本地处理，无信息外泄风险。


## 下载与启动 V4

    下载 `QuizAssistant-Portable-v4-Windows-x64.zip`。

1. 准备 Windows x64 电脑，并安装 Microsoft Edge。
2. 将整个 ZIP 解压到有写入权限的文件夹。
3. 阅读文件夹中的 `使用说明.txt`、`使用教程-v4.md` 或 `使用教程-v4.docx`。
4. 根据需要双击下列启动入口。

便携版无需安装 Python 或其他依赖。不要直接在压缩包中运行，不要单独移动 EXE，也不要删除 `_internal`、`data` 等配套文件夹。

| 启动入口 | 用途 |
|---|---|
| `启动助手.cmd` 或 `QuizAssistant.exe` | 默认使用内置题库进入高校练习 |
| `高校练习.cmd` | 使用内置题库填写已适配的 40 题高校练习 |
| `高校模考.cmd` | 使用内置题库填写已适配的 300 题高校模考 |
| `只读模式.cmd` | 显示高校练习答案建议，不自动勾选 |
| `导入题库.cmd` | 从本地文档或表格构建自建题库 |
| `自建题库答题.cmd` | 使用自建或合并题库，进行网页填写或离线查询 |

## V4离线查答案功能：
1. 在“自建题库答题”菜单选择离线查询。
2. 按提示选择单选、多选或判断题。
3. 粘贴题干和选项，一行一个选项，例如 `A. 选项内容`。
4. 单独输入大写 `END` 结束本题，查看匹配结果。
5. 按提示继续查询，或输入 `q` 退出。

判断题可省略“正确/错误”选项。离线查询不需要浏览器和网络，适合尚未适配网页的其他考试题库。

## 补充说明

### 匹配和网站适配（扫一眼就行）

- 题号和选项顺序可以不同，答案按选项内容映射。
- 匹配会规范全半角、大小写和空白，但题干、题型及选项集合需要一致，不依靠模糊相似度自动猜答案。
- 判断选项应与题库用语一致，不保证将“是”“正确”“√”视为同义词。
- 任意排版文件不保证全部识别，请检查预览、有效题数和错误报告。
- 网页结构或控件异常时可能停止，此时先检查浏览器中的现有选择，避免刷新有限次数试卷。
- 新版不能接管旧版进程已经打开的浏览器或试卷。请在当前试卷完成后再切换版本，不要同时启动两个助手。

### 报告和验证（扫一眼就行）

便携版报告保存于 `user-data/reports/`，区分精确匹配、人工处理、随机猜测和跳过题。**匹配率、勾选成功率不等于平台评分正确率，不保证满分。**

开发期间，用户反馈一套 40 题练习获得 100 分，仅代表该次练习结果。V3 完成了 38 项单元测试及便携程序未知题继续路径测试；V4 完成了 56 项单元测试，以及导入解析、离线匹配和本地网页勾选验证。新版打包测试未通过反复进入真实模考消耗考试次数。

### 隐私和分享

导入文件在本地解析，不上传文件，不访问文档中的链接，不运行宏或 Excel 公式。密码、验证码和身份信息仅在网页中由本人填写。

原始分发包按白名单打包并进行隐私检查，排除开发者账号、密码库、Cookies、Token、浏览器会话、个人资料、截图和历史日志。运行后会生成使用者自己的 `user-data`，其中可能包含登录会话、自建题库和报告。


# 再次分享请转发原始干净 ZIP，不要转发使用后的文件夹或 `user-data`(其中包含你的数据)。


上传 GitHub 时也应排除这些私人数据，共享题库前请确认拥有相应传播权限。便携 ZIP 建议作为 GitHub Releases 附件发布。

### 常见问题

| 问题 | 处理方法 |
|---|---|
| 双击无法启动 | 完整解压，确认 Windows x64、Edge 已安装且目录可写 |
| 浏览器配置被占用 | 检查是否重复启动；不要在计时试卷中随意重启 |
| 找不到自建题库 | 先导入文件，核对预览后输入 `SAVE` |
| 有效题数少于原文件 | 查看报告，确认是否去重、缺答案或格式不符合要求 |
| 题目全部未知 | 检查题库范围、题型、题干及选项内容 |
| 某题答案冲突 | 当前题人工处理，核对原资料后重新导入 |
| 导入后无法填写其他网站 | 该网站需要另行适配，可先使用离线查询 |
| 退出后浏览器关闭 | 属于正常行为，请在提交并保存反馈后再退出 |

## 各版本更新说明及功能

### V1：基础练习辅助（历史版本，不推荐使用）

**本版功能：**

- 内置 4732 道有效题目，支持单选、多选和判断题匹配。
- 提供高校练习只读建议、自动勾选和选项换序映射。
- Windows x64 便携运行，无需安装 Python 和依赖。
- 登录和最终提交由本人完成。

**版本特点：** 建立题库、匹配和练习填写的基础流程。未知题可能阻止整套填写，建议使用 V3 或 V4。

### V2：增加高校模考（历史版本，不推荐使用）

**相较 V1 的更新：**

- 分开提供 40 题高校练习与 300 题高校模考入口。
- 模考打开网页前要求输入 `MOCK` 确认。
- 改进整套选中状态复核及页面变化后的异常处理。

**本版功能：** 保留 V1 的题库、只读建议、练习填写、便携运行和本人提交，增加已适配高校模考填写。仍有必须全套题唯一匹配才能开始填写的限制，建议使用 V3 或 V4。

### V3：未知题可继续，优先用于广东省学生军事理论知识竞赛

**相较 V2 的更新：**

- 取消全套题必须完全匹配才能填写的限制，先完成已匹配题。
- 未知题支持输入字母、网页手选后 Enter、`s` 跳过、`r` 明确随机猜测。
- 报告区分精确匹配、人工处理、随机猜测及跳过题。
- 补充分发隐私检查，排除登录会话、Cookies、Token 和历史日志。

**本版功能：** 内置 4732 题、单选/多选/判断匹配、选项换序映射、高校练习和高校模考填写、只读建议、未知题继续、结果复核及本人提交。该版本最适配广东省学生军事理论知识竞赛的已核验页面。

### V4：自建题库，扩展更多考试辅助场景

**相较 V3 的更新：**

- 保留内置题库和 V3 既有功能，独立新增“导入题库”和“自建题库答题”入口。
- 支持 DOCX、XLSX、CSV、TSV、TXT、Markdown、JSON 本地导入。
- 增加导入预览、去重、错误定位和答案冲突提示。
- 自建题库独立保存，生成索引，再次保存前备份旧库。
- 支持仅使用自建题库，或与内置题库合并使用。
- 新增离线查答案，辅助更多尚未适配网页的考试。
- 附带导入模板、Word/Markdown 完整教程及更新记录。

**本版功能：** 覆盖 V3 的练习、模考和未知题处理能力，并支持从文档、表格构建题库及离线检索。自建题库可用于现有适配网页，其他网站的自动填写仍需另行适配。
